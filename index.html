🚗 ServiceMaster

Vehicle Maintenance Management System

✅ Ready to Run

🚀 Quick Start (Docker - Recommended)

Run the application with a single command:

./run-quick.sh

Or manually:

docker run -d \
--name servicemaster-app \
-p 8081:8081 \
-v "$(pwd):/app" \
-w /app \
ghcr.io/cirruslabs/flutter:latest \
sh -c "flutter pub get && flutter run -d web-server --web-port=8081 --web-hostname=0.0.0.0"

🔧 Alternative Method (Build First)

If you prefer to build and serve static files:

./build-and-run.sh

This will:

  1. Build the Flutter web app using Docker
  2. Serve it on localhost:8081 using Python

  1. Engine Oil Change (250 hrs/5,000 km)
  2. Air Filter (500 hrs/10,000 km)
  3. Fuel Filter (500 hrs/12,000 km)
